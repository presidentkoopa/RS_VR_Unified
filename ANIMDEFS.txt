// A NEW ROOT LUMP FOR THIS PACKAGE. No lane before the wheel shipped an
// ANIMDEFS, so build.ps1's $optionalLumps did not list one and this file
// would have been left out of the pk3 entirely -- silently, because a missing
// ANIMDEFS is not an error. TexMan.GetCanvas() simply returns null for every
// name that was never declared, and the wheel's card faces would come up
// blank with nothing in the log. 'ANIMDEFS.txt' has been added to
// $optionalLumps in build.ps1 for exactly that reason.
//
// Content below is RS_WeaponWheel/animdefs.txt verbatim. WRFACE00..11 do not
// collide with anything: the only texture names this package defines are the
// RSGB*/RSHM*/RSHP* sprite fallbacks in TEXTURES.txt.

// Canvas faces for the cards.
//
// A canvas texture is a blank texture the engine hands ZScript a drawing
// surface for. TexMan.GetCanvas() returns null for anything that is NOT
// declared here, so these lines are not optional setup -- they are the whole
// mechanism.
//
// A FIXED POOL, declared up front, because that is the only way canvas
// textures exist: there is no allocate-on-demand. Twelve is one per ring slot
// with headroom. A ring that needs MORE than twelve draws every card composed
// instead -- all of it, not just the overflow, because a ring split between
// two card styles reads worse than a ring uniformly in the plainer one.
//
// 140x100 matches the card's own 3.5 x 2.5 proportions, so artwork painted
// here is not stretched when it lands on the quad. `fit` gives the texture a
// display size, which is what stops it being treated as a 140-map-unit wall.

canvastexture WRFACE00 140 100 fit 140 100 WorldPanning
canvastexture WRFACE01 140 100 fit 140 100 WorldPanning
canvastexture WRFACE02 140 100 fit 140 100 WorldPanning
canvastexture WRFACE03 140 100 fit 140 100 WorldPanning
canvastexture WRFACE04 140 100 fit 140 100 WorldPanning
