// ---------------------------------------------------------------------
// The store/draw confirm cue, SHIPPED HERE AS OF 2026-08-26.
//
// doSwap has always asked for "rs_fx_holster" or "rs_allclear_ready" by
// name, and CVARINFO's own note claimed that was fine because "whichever
// loaded weapon pack happens to define them supplies them". Only one thing
// on disk anywhere ever defined either name: RS_Main's SNDINFO -- and
// RS_Main is not part of this family and is not a declared dependency of
// this pk3 (zscript.txt's header is explicit that no specific pack is
// named). GZDoom resolves an undefined sound to SILENCE rather than to an
// error, so the confirm sound had simply never played for anyone running
// these mods without RS_Main, and nothing said so. A cvar, a menu row and a
// style selector all existed for a cue that could not sound.
//
// OWN LOGICAL NAMES AND OWN LUMP NAMES, exactly like the flashlight click
// set above and for the same stated reason: this pk3 must not need any
// other pk3 loaded to have a sound, and must not silently override a lump
// another pk3 owns. RSHO* is this repo's prefix; RS_HardPoints ships the
// identical audio under RSHP* so the two siblings do not collide either.
//
// Audio source: RS_Main's Sounds/combatfx/foley/HOLSTR{,2,3} (the $random
// 3-variant holster clunk) and Sounds/combatfx/allclear/READYBP (the
// li-gnrcwpn plasma ready beep). Copied, not referenced -- same author,
// same project family.
$random rs_holster_fx_store {
	rs_holster_fx_store1
	rs_holster_fx_store2
	rs_holster_fx_store3	}

rs_holster_fx_store1	RSHOHOL1

// ============================================================
// from RS_Reload  (SNDINFO.txt)
// ============================================================
// Reload sounds, addressed by FEED FAMILY and never by weapon.
//
// A missing sound is not an error in GZDoom -- it is a log line and silence --
// so an unmapped logical name here reads in play as the beat not firing at all.
// Every name rr_feed.zs can hand to A_StartSound is defined below, even the ones
// still pointing at a placeholder, so a beat is never silent for a reason that
// takes a log dive to find.
//
// The files these should point at are Rusted Legacy's, which already exist and
// are already timed to these sequences.
//
// rr/magdraw WAS COMMENTED OUT, fixed 2026-08-26. It sat as the last line of
// this prose block with a leading '//', while the two definitions beside it
// did not -- so it read as an example rather than a definition and was never
// registered. It is SndDraw's default return (rr_sequence.zs:262-266), so the
// draw beat was silent for BOX, BOLT, POD and BELT -- the majority of feeds --
// under a header six lines up asserting every name is defined. Exactly the
// silent-failure shape that comment was written to prevent.
rr/magdraw    DSSWTCHN
rr/shelldraw  DSSWTCHN
rr/celldraw   DSSWTCHN

rr/magin      DSSWTCHX
rr/shellin    DSSWTCHX
rr/cellin     DSSWTCHX
rr/podin      DSSWTCHX

rr/stow       DSSWTCHN
rr/drop       DSBDCLOS

// ============================================================
// from RS_WeaponWheel  (sndinfo.txt)
// ============================================================
// The rig's own voice. Logical names are namespaced wristrig/*, lump names
// are wr_* (sounds/wr_*.ogg) -- neither collides with the DDZCLK*/RSHO*/RSHP*
// set above, and the wheel's eight .ogg files land in sounds/ with no path
// collision at all, which stage.ps1 confirms.
// The rig's own voice.
//
// It used to borrow the engine's menu aliases -- menu/cursor, menu/choose --
// which was the right call while there was nothing else, but they are the flat
// UI beeps of whichever game is loaded and they sound exactly like the pause
// menu. This is not the pause menu; it is a thing on your arm.
//
// Namespaced wristrig/* so nothing here can collide with a game's own sounds or
// with another mod's.

wristrig/move   wr_move
wristrig/lock   wr_lock
wristrig/open   wr_open
wristrig/close  wr_close
wristrig/nope   wr_nope

wristrig/tick1  wr_tick1
wristrig/tick2  wr_tick2
wristrig/tick3  wr_tick3

// Three ticks, picked at random.
//
// A fan opens often enough that one fixed sample starts to grate -- the ear
// notices an identical transient repeating far faster than it notices the
// sound itself. Rotating three kills that for free.
$random wristrig/tick { wristrig/tick1  wristrig/tick2  wristrig/tick3 }

// Menu volume, not world volume, and nothing here should duck anything.
$limit wristrig/move  2
$limit wristrig/tick  2
